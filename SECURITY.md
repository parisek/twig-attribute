# Security policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 1.6.x   | Yes       |
| < 1.6   | No        |

Only the latest minor release of the current major version gets security fixes.

## Report a vulnerability

Do not open a public issue for a vulnerability.

Use GitHub private vulnerability reporting:

1. Open the [Security tab](https://github.com/parisek/twig-attribute/security).
2. Select "Report a vulnerability".

You can also go to the [advisory form](https://github.com/parisek/twig-attribute/security/advisories/new) directly.

We aim to reply within 7 days.

## What to include

- The affected version of `parisek/twig-attribute`.
- The PHP and Twig versions you use.
- Steps to reproduce the problem.
- The impact, as you understand it.

## What happens next

We confirm the problem and prepare a fix. The fix ships as a patch release with a GitHub Security Advisory.
